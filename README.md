# 💫 About Me

I'm Pratik Mane, a B.Tech Computer Science & Engineering student specializing in Artificial Intelligence & Analytics at MIT ADT University, India. I work across Artificial Intelligence, Machine Learning, and Full-Stack Development, with a focus on building practical software and AI-based applications.

My work includes projects in Deep Learning, Natural Language Processing, and Full-Stack Web Development. I've worked on projects such as Plant Disease Detection and Fake News Detection, along with responsive web applications and client projects.

I primarily use Python for AI/ML projects and JavaScript-based technologies for full-stack development, building machine learning applications, REST APIs, and responsive web interfaces.
